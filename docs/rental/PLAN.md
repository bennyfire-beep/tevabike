## 2. פוליסת גניבה ואובדן – טיוטה

### 2.1 עקרונות
1. **מסלול ההגנה (90 ₪) לא מכסה גניבה ואובדן מלא.** הוא מכסה רק נזק פיזי עד 1,000 ₪. זה חייב להיות כתוב באופן בולט, עם סימון נפרד בחוזה.
2. **השוכר אחראי לאופניים מרגע המסירה ועד ההחזרה בפועל** (כולל סוללה, מטען, מנעול ומפתחות).
3. האחריות בגניבה **מדורגת לפי התנהגות השוכר**: אם השוכר שמר על הכללים, הוא משלם סכום קבוע ומוגבל; אם התרשל, הוא משלם את הערך המוסכם המלא.

### 2.2 חובות השוכר (תנאים לסכום המוגבל)
- לנעול את האופניים במנעול שנמסר, **לחפץ קבוע**, בכל פעם שהם לא בהשגחה ישירה.
- לא להשאיר את המפתח במנעול או בסוללה ולא להשאיר אופניים בלי השגחה בלילה.
- לא למסור את האופניים לאדם שלא רשום בחוזה.
- בגניבה: להודיע לטבע בייק **מיד** (טלפון/וואטסאפ), להגיש תלונה במשטרה **תוך 24 שעות**, ולמסור את אישור התלונה ואת **המנעול והמפתחות** שנשארו.

### 2.3 טבלת אחריות (המספרים בסוגריים מרובעים – להחלטה)

| מצב | מה השוכר משלם |
|---|---|
| גניבה, כל התנאים בסעיף 2.2 קוימו | השתתפות קבועה בגניבה: **[X ₪]** לזוג אופניים (מוצע: ההשתתפות העצמית של פוליסת טימו, ואם אין כיסוי – 25%–30% מהערך המוסכם) |
| גניבה בלי נעילה / מפתח הושאר / אין תלונה במשטרה / מסירה לאחר | **הערך המוסכם המלא** של האופניים לפי נספח הערכים |
| אובדן (לא גניבה) או אי-החזרה עד [24] שעות אחרי המועד, בלי קשר | הערך המוסכם המלא + דמי השכרה לכל יום עיכוב; לאחר [48] שעות – הגשת תלונה במשטרה על אי-החזרה |
| האופניים נמצאו אחרי תשלום | החזר מה ששולם, בניכוי עלות תיקון נזקים (לפי חנות טימו פאן) ודמי השכרה לתקופה שבה לא היו זמינים |

### 2.4 נספח ערכים מוסכמים
טבלה חתומה שמצורפת לכל חוזה: דגם, מספר שלדה, **ערך מוסכם** (יורד לפי גיל: למשל 100% בשנה הראשונה, 85% בשנה השנייה...), ומחירון חלפים עיקריים (סוללה, מעביר, בולם, גלגל, צג). **צריך מטימו: מחיר קנייה של דגם ה-Whistle ומחירון חלפים.**

### 2.5 למה זה חשוב משפטית
- חוזה השכרה מקוון הוא **חוזה אחיד**. תנאי מקפח (למשל "השוכר משלם כל סכום שנקבע לפי שיקול דעתנו") עלול להתבטל. לכן: סכומים קבועים מראש, טבלה שקופה, אסמכתה מהחנות לכל חיוב וזכות השגה.
- סימון נפרד ("אני מבין שמסלול ההגנה לא מכסה גניבה ושאחריותי היא X / הערך המלא") מחזק את האכיפה.

## 3. איך "משאירים את האשראי אצלנו" – בלי לשמור פרטי כרטיס

**אנחנו לא שומרים מספר כרטיס בשום מצב** (זה מחייב תקן PCI ומסוכן). במקום זה משתמשים בשני כלים של חברת הסליקה:

### 3.1 טוקן (שמירת כרטיס אצל חברת הסליקה)
- בתשלום הראשון חברת הסליקה שומרת את הכרטיס אצלה ומחזירה לנו **מזהה (טוקן)** + 4 ספרות אחרונות.
- עם הטוקן אפשר לחייב **בהמשך** סכומים נוספים (נזק מעל 1,000 ₪, גניבה, איחור) – **רק** בהתאם להרשאה שהלקוח חתם עליה.
- הטוקן נמחק [30] יום אחרי סגירת ההשכרה בלי חוב פתוח.

### 3.2 תפיסת מסגרת (J5 / "פיקדון" שלא נגבה)
- במסירת האופניים: **תפיסת מסגרת של [1,500 ₪] לזוג** בכרטיס. הכסף לא יורד, רק "נתפס" במסגרת האשראי.
- בהחזרה תקינה: משחררים את התפיסה מיד.
- בנזק: מחייבים מתוך התפיסה את הסכום המאושר בלבד ומשחררים את השאר.
- **מגבלה:** תפיסת מסגרת תקפה מספר ימים בלבד (משתנה לפי חברת הסליקה/המנפיק) – מתאים להשכרה של יום-יומיים, ולכן נעשית **ביום המסירה** ולא ביום ההזמנה.

### 3.3 הזרימה המלאה
1. **הזמנה:** הלקוח משלם השכרה + הגנה (אם בחר) → נוצר טוקן.
2. **מסירה:** תפיסת מסגרת J5 על הטוקן, צילום מצב, מספר שלדה, אחוז סוללה.
3. **החזרה תקינה:** שחרור התפיסה + קבלה במייל.
4. **נזק:** תיעוד בצילום → האופניים עוברים לחנות טימו פאן → החנות מעלה אסמכתה עם עלות → המערכת מחשבת (מנכה 1,000 ₪ אם יש הגנה) → **הודעה ללקוח עם התמונות והאסמכתה ו-[3] ימי עסקים להשגה** → חיוב מהתפיסה/מהטוקן.
5. **גניבה:** חיוב לפי טבלת 2.3 דרך הטוקן, רק אחרי תיעוד ושליחת הודעה מסודרת ללקוח.

> הודעה מראש + אסמכתה + חתימה על הרשאה הם מה שמונע הכחשת עסקה (chargeback) מול חברת האשראי.

### 3.4 סליקה – הוחלט
- **עכשיו: קישורי Arbox קבועים** (קישור להשכרה 4 שעות, ליום מלא ולמסלול הגנה; הלקוח מסמן כמות). מגדירים ב-`PAY_LINKS` ב-`lib/rental.ts`.
- **בקרוב: רווחית** – קישור תשלום אוטומטי לכל הזמנה עם הסכום המדויק. ייכנס במקום אחד בקוד (`paymentLines` ב-`lib/rental.ts`).
- **עד שרווחית מחוברת אין פיקדון אוטומטי בכרטיס** (Arbox לא תומכת בזה). בינתיים פיקדון נלקח ידנית במסירה.

**שאלות לרווחית במשא ומתן:**
1. יצירת קישור תשלום דרך API לכל הזמנה, עם סכום ופירוט שורות?
2. הודעה אוטומטית לאתר (webhook) כשהתשלום עבר, כדי לסמן "שולם" לבד?
3. שמירת כרטיס (טוקן) וחיוב מאוחר יותר בלי שהלקוח יזין שוב את הכרטיס?
4. תפיסת מסגרת (J5): אפשרי? לכמה ימים? אפשר לחייב חלק ממנה ולשחרר את השאר?
5. קבלה/חשבונית מס-קבלה אוטומטית לכל תשלום ולכל חיוב נזק?
6. עמלות: לעסקה, לטוקן, ל-J5, דמי מנוי.

### 3.5 (ארכיון) חברת סליקה – האפשרויות שנבדקו
Arbox (שבשימוש היום לחוגים) לא בנויה לפיקדונות ולחיובים חוזרים להשכרה. צריך חשבון סליקה של טבע בייק בחברה שתומכת **בטוקנים + J5 + API + הפקת קבלות**, למשל: Cardcom, PayPlus, Tranzila, Grow (משולם), Hyp. לבקש מכל אחת: עמלה, תוקף J5, עלות טוקן, אינטגרציה עם חשבונית.

## 4. חוזה דיגיטלי חתום – מה נבנה

**הבסיס המשפטי:** לפי חוק חתימה אלקטרונית, חתימה אלקטרונית "רגילה" מספיקה לחוזה השכרה, בתנאי שאפשר להוכיח **מי** חתם ו**על איזה נוסח**. לכן נשמור ראיות:

| ראיה | איך |
|---|---|
| זיהוי החותם | קוד חד-פעמי (OTP) בוואטסאפ/SMS לטלפון של הלקוח (יש כבר חיבור וואטסאפ באתר) |
| הסכמה מפורשת | סימון נפרד לכל סעיף מרכזי: (1) תנאי השכרה ובטיחות, (2) מסלול הגנה וחריגים, (3) **מדיניות גניבה**, (4) **הרשאה לחיוב כרטיס בהמשך עד תקרה** |
| חתימה | חתימה ביד על המסך (קנבס) + שם מלא מוקלד |
| נוסח קבוע | כל נוסח חוזה נשמר עם מספר גרסה; ההזמנה שומרת איזו גרסה נחתמה |
| שלמות | PDF של החוזה החתום + טביעת אצבע דיגיטלית (SHA-256), שעה, IP, דפדפן |
| עותק ללקוח | PDF נשלח במייל (Resend) ונשמר באחסון פרטי (Supabase Storage) |

**גישה:** רק מנהלים ורכזים; טימו פאן מקבל בדוח רק נתונים כספיים – לא חוזים, לא תעודות ולא פרטי כרטיס.

## 6. החלטות שצריך לסגור (חוסמות את שלבים 1–2)

1. **חברת סליקה** – איזו? (סעיף 3.4)
2. **ערך מוסכם** של כל זוג Whistle + מחירון חלפים (מטימו).
3. **השתתפות בגניבה** (X ₪) כשהשוכר עמד בכללים – והאם פוליסת טימו מכסה גניבה מהלקוח בשטח.
4. **גובה תפיסת המסגרת** לזוג (מוצע 1,500 ₪).
5. **תקרת הרשאת חיוב** בחוזה (מוצע: הערך המוסכם המלא של האופניים).
6. **ביטולים ומזג אוויר** – עד מתי ביטול חינם?
7. **שעות מסירה והחזרה**, ומה נחשב "יום מלא".
8. **גיל מינימלי** ותנאי כשירות לפי הרלב״ד לדגם הספציפי.
9. **מסלול "הגנה פלוס"** אופציונלי שמכסה גם גניבה? (רק אם המבטח מאשר.)

## 7. מה נבנה (שלב 3 + 4 + חלק מ-5 ו-6)

| קובץ | מה |
|---|---|
| `lib/rental.ts` | מחירים, משבצות זמן, קישורי תשלום, טבלת מידות לפי גובה, סכומי מדיניות. **כאן משנים מספרים** |
| `lib/rental-contract.ts` | נוסח ההסכם (טיוטה) + 4 האישורים הנפרדים + מספר גרסה |
| `supabase/migrations/20261107_rental_bikes_and_bookings.sql` | טבלאות, פונקציית הזמנה שמונעת הזמנה כפולה של אותם אופניים, תיקיות תמונות וחתימות |
| `app/rent/page.tsx` | הדף הציבורי: מדריך מידות, האופניים עם תמונות, הזמנה, הסכם וחתימה |
| `app/api/rent/route.ts` | זמינות, חישוב מחיר בשרת, שמירת ההסכם החתום + טביעת אצבע, מייל לבני וללקוח |
| `app/admin/coordinator/rentals/page.tsx` | ניהול: הוספת אופניים, העלאת תמונות, מידה וטווח גובה; רשימת הזמנות, סטטוס, ההסכם והחתימה |

**מידות:** S 150–165 · M 165–178 · L 178–190 · XL 190–205 ס״מ. כל אופניים יכולים לקבל טווח משלהם בדף הניהול. הלקוח מזין גובה לכל רוכב, מקבל המלצה ורואה רק אופניים שמתאימים ופנויים.

**לפני שפותחים לציבור:**
1. להריץ את קובץ ה-migration ב-Supabase.
2. להעלות אופניים ותמונות במסך הניהול.
3. להכניס קישורי Arbox ב-`PAY_LINKS`.
4. לעדכן את סכומי המדיניות (פיקדון, השתתפות בגניבה, ערך מוסכם, שעות) לפי מה שייסגר עם טימו.
